==============================================================
AI Tools Marathi (AI सोप्या मराठीत) - cPanel / Hosting मार्गदर्शक
==============================================================

नमस्कार! ही फाईल तुमच्या cPanel File Manager मध्ये सबफोल्डर (Subfolder) मध्ये 
वेबसाईट अपलोड करण्यासाठी तयार करण्यात आली आहे.

या पॅकेजमधील सर्व लिंक्स 'Relative Paths' (सापेक्ष मार्ग) वापरून सेट करण्यात 
आल्या आहेत, ज्यामुळे तुम्ही ही वेबसाईट कोणत्याही सबफोल्डरमध्ये अपलोड केली 
तरीही:
१. ब्राउझर URL मध्ये सबफोल्डरचे नाव जसेच्या तसे दिसेल.
२. सर्व मेनू लिंक्स (मुख्यपृष्ठ, AI Tools, Categories, Prompts इ.) कोणत्याही एररशिवाय उघडतील.
३. CSS स्टाइल्स, JavaScript आणि टूल्स पेजेस सुरळीतपणे काम करतील.

--------------------------------------------------------------
पायरी-दर-पायरी मार्गदर्शक (Step-by-Step Instructions):
--------------------------------------------------------------

१. तुमच्या cPanel मध्ये लॉगिन करा.
२. "File Manager" वर क्लिक करा.
३. "public_html" फोल्डरमध्ये जा.
४. "public_html" मध्ये नवीन फोल्डर (Subfolder) तयार करा. 
   (उदा. 'aitools' किंवा 'marathi-ai')
   आता तुमचा मार्ग असा असेल: public_html/aitools/
५. त्या सबफोल्डरच्या आत जा आणि "Upload" बटणावर क्लिक करा.
६. 'ai-tools-marathi.zip' ही फाईल सिलेक्ट करून अपलोड करा.
७. अपलोड पूर्ण झाल्यावर, 'ai-tools-marathi.zip' वर राईट-क्लिक करा आणि "Extract" निवडा.
८. आता सर्व फाईल्स त्या फोल्डरमध्ये अनझिप होतील:
   - index.html
   - tools.html
   - categories.html
   - prompts.html
   - learn.html
   - compare.html
   - audience.html
   - about.html
   - css/ (custom.css)
   - js/ (main.js, tools.js, search.js, prompts.js)
   - tools/ (सर्व 19 टूल्सचे HTML पेजेस)
   - .htaccess

९. आता तुमच्या ब्राउझरमध्ये खालीलप्रमाणे वेबसाईट उघडा:
   https://yourdomain.com/aitools/
   किंवा
   https://yourdomain.com/aitools/index.html

सर्व पेजेस आणि मेनू लिंक्स अगदी व्यवस्थित दिसतील!
--------------------------------------------------------------
कोणतीही समस्या असल्यास:
- सर्व फाईल्स थेट त्या सबफोल्डरमध्ये असाव्यात (आणखी एका सबफोल्डरच्या आत नसाव्यात).
- .htaccess फाईल समाविष्ट असल्याची खात्री करा (cPanel File Manager मध्ये "Show Hidden Files" ऑन करा).
